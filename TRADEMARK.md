# Trademarks

## The short version

The licence covers the code. It does not cover the name.

"Audion" is the name under which the author publishes this software, and the
Audion mark identifies its origin. You are free to use, modify and redistribute
the code under the terms of the Apache License 2.0 — but a derivative work has to carry a
name of its own.

## What is allowed

- Stating, plainly and truthfully, that your work is based on this project:
  "based on Audion Yandex Portable", "a fork of Audion Yandex Portable",
  "compatible with Audion Yandex Portable".
- Keeping the copyright and licence notices that the licence requires, including
  the ones that mention Audion.
- Referring to the project by its name when writing about it, reviewing it or
  linking to it.

## What is not allowed

- Naming your product "Audion", "Audion <anything>", or a name close enough to
  be mistaken for one.
- Using the Audion mark, logo or icon as the identity of your product, in its
  interface, in a domain name, in a store listing or in a repository name.
- Presenting a modified build as the official one, or implying that the author
  endorses, maintains or supports it.

## Why this file exists

The Apache License 2.0 says the same in section 6: the licence grants no permission to use the trade names, trademarks, service marks or product names of the licensor. This file states it in plain words so that nobody has to read a licence to find out.

Nothing here restricts the rights the licence grants you over the code. It only
says that those rights were never rights to the name — which is true of every
licence, and is written down here so that it does not have to be argued about.
