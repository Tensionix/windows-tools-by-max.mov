# Audion Windows Tools by Max.mov

Audion Windows Tools by Max.mov — интерактивный компаньон к большому гайду Max.mov по Windows и самостоятельный помощник по подготовке рабочей станции. Это не построчная копия [семичасового ролика](https://www.youtube.com/watch?v=ITdecD6R0Yw): знакомая последовательность дополнена состояниями, откатом, автоматизацией и собственными практическими сценариями.

## Назначение

Проект не применяет все твики автоматически. Он организует проверенные действия, открывает нужные разделы Windows и внешние утилиты, выполняет поддерживаемые команды и показывает, что оператор должен проверить. Если пользователь не является специалистом, он может пройти большую часть маршрута по карточкам, не разыскивая каждую системную страницу вручную, — но обязан читать описание перед нажатием.

## Приоритет источников

- В первую очередь используются штатные возможности Windows и рекомендации Microsoft.
- Метка `official` означает документированный или поддерживаемый путь Microsoft, производителя оборудования либо автора целевого продукта. Это не обещание, что настройка нужна каждому компьютеру.
- Метка `Max.mov guide` означает, что конкретный шаг или рекомендация точно присутствует в гайде Max.mov. Она не означает отдельного одобрения реализации этой карточки.
- Метка `Max.mov approved` зарезервирована для рекомендации или реализации, которую Max.mov одобрил отдельно и явно.
- Метка `unofficial` сохраняет полезные обходные методы, экспериментальные параметры и практику сообщества, но явно отделяет их от официального слоя. Для системных твиков это также предупреждение: механизм не документирован Microsoft и может измениться после обновления Windows.
- Собственные расширения Audion не выдаются за точную цитату из ролика. Краткая карта отличий находится в `VIDEO_COMPANION_RU.md`.

## Быстрый Старт

1. Дважды щёлкните `Start.exe` — это единственная точка входа.
2. Выберите нужный раздел настройки.
3. Прочитайте описание карточки и предупреждение о риске.
4. Выполняйте по одному действию.
5. Подтвердите результат перед переходом дальше.
6. Перезагрузите Windows, если этого требует процедура.

Программа сначала ищет портативный PowerShell 7 внутри проекта, затем системный PowerShell 7, а при их отсутствии использует встроенный Windows PowerShell 5.1. Установка PowerShell 7 желательна для полностью автономного комплекта, но не обязательна для первого запуска.

Права администратора используйте только для действий, которым они действительно нужны. Перед изменением дисков, загрузки, реестра, драйверов или системных политик создайте резервную копию.

## Интерфейс

Карточка может выполнить команду, открыть настройки Windows, папку, URL или внешнюю утилиту либо показать ручной checklist. Тип действия и необходимые права должны быть понятны до запуска. Кнопка, открывающая инструкцию, не равна автоматическому изменению системы.

## Безопасность

- Перед общей настройкой создайте точку восстановления или образ системы.
- Проверяйте загруженные installers.
- Не применяйте registry/boot-изменения без понятного rollback.
- Считайте очистку диска, разметку, firmware и удаление драйверов операциями высокого риска.
- Не складывайте несколько latency/timer-инструментов без измерений.
- Храните recovery media и важные данные отдельно от настраиваемой системы.
