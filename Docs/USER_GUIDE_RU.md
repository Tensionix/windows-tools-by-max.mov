WPF-интерфейс для настройки Windows 11 после чистой установки. Это интерактивный компаньон-ремикс [гайда Max.mov](https://www.youtube.com/watch?v=ITdecD6R0Yw), а не его построчный визуализатор. Приложение собирает 13 разделов из `Manifests\Section##.psd1`, показывает карточки действий и использует единый движок `Engine\TweakEngine.psm1`.

Рекомендации Microsoft и штатные механизмы Windows имеют приоритет. Карточки `official` опираются на документированные источники Microsoft, производителя оборудования или автора продукта; `Max.mov guide` отмечает шаги, точно присутствующие в гайде Max.mov; `Max.mov approved` используется только для отдельно и явно одобренной рекомендации или реализации; `unofficial` сохраняет альтернативные и экспериментальные решения, но не маскирует их под официальный путь. Точные отличия от ролика описаны в `VIDEO_COMPANION_RU.md`.

## Быстрый старт

Дважды щёлкните `Start.exe` в корне проекта. Это единственная точка входа: она сама находит PowerShell и даёт окну собственный значок в панели задач.

Если Windows отказывается запускать неподписанный локальный файл, снимите блокировку в свойствах файла (правая кнопка → Свойства → Разблокировать). На крайний случай в комплекте есть `Engine\Launch.bat` — он выбирает PowerShell так же, но без исполняемого файла. Это запасной путь, а не второй способ запуска.

Порядок поиска PowerShell:
1. `Engine\PowerShell\pwsh.exe` — встроенный портативный PowerShell 7.
2. Системный `pwsh.exe` из `PATH` — запасной вариант.
3. Встроенный в Windows `powershell.exe` 5.1 — автономный резерв для первого запуска.
4. Для полностью портативного комплекта запустите `Install\Install-Portable-PowerShell.cmd` или используйте кнопку установки в интерфейсе.

App.ps1 перезапускает себя в STA-режиме и с правами администратора, затем импортирует движок, загружает все манифесты и открывает WPF-окно.

`Engine\WindowIdentity.psm1` назначает окну собственную WPF-иконку, Win32-иконки малого и большого размера, `AppUserModelID` и свойства повторного запуска через `Start.exe`. Поэтому панель задач показывает значок приложения, а не значок процесса PowerShell.

## Что делают кнопки интерфейса

- Применить - запускает Apply для текущего подраздела. Если выбраны чекбоксы справа от карточек, выполняются только выбранные твики; если выбора нет, выполняется весь подраздел.
- Отменить - запускает Revert для текущего подраздела или выбранных твиков.
- Обновить - заново выполняет Detect для видимых карточек и перерисовывает статусы.
- Очистить - удаляет JSON-бэкапы из `Data\backups\` рядом с программой, очищает лог и сбрасывает локальные отметки. Состояние приложения портативное и не пишется в %LOCALAPPDATA%.
- ДОКИ - открывает весь каталог `Docs`: руководство пользователя, технический README, материалы к ролику и остальные документы проекта. Приложение не выбирает конкретный файл за пользователя.
- Установить PowerShell - запускает Install\Install-Portable-PowerShell.cmd в отдельном elevated cmd.exe; установщик скачивает последнюю x64 ZIP-сборку PowerShell с GitHub и кладет ее в Engine\PowerShell\.
- EN/RU - переключает язык интерфейса, включая названия разделов и карточек.
- Log - показывает или скрывает правую панель журнала.
- Terminal - показывает или скрывает встроенный PowerShell-терминал; введенная команда выполняется локально в отдельном runspace.

## Типы карточек и действий

- link - открывает внешний URL через браузер по умолчанию.
- deeplink - открывает ms-settings:, microsoft-edge: или shell: URI.
- manual - ручной чеклист без автоматического изменения системы.
- registry - пишет значение реестра и сохраняет предыдущее состояние в JSON-бэкап.
- script - выполняет PowerShell scriptblock из манифеста; может иметь Apply, Revert и Detect.
- service - меняет службу Windows через Set-Service, Start-Service, Stop-Service.
- feature - включает или отключает optional feature через Enable/Disable-WindowsOptionalFeature.
- powerscheme - импортирует .pow через powercfg -import, активирует через powercfg -setactive.

#### 0.4 Установка без USB (опционально)

- **Примечание: не рекомендуется при переходе с Legacy на UEFI** (id=`no-usb-note`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: Установка без USB-носителя через создание временного раздела на 12 ГБ работает на большинстве систем, но не подходит при переходе с Legacy BIOS на режим загрузки UEFI.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: Если вы переходите с Legacy/MBR на UEFI/GPT — используйте USB-накопитель. Этот метод лучше всего подходит для чистой переустановки на системе, уже работающей в режиме UEFI.
- **Открыть Управление дисками для создания установочного раздела** (id=`open-disk-management-partition`; kind=`deeplink`; control=`button`; source=`official`; нужны права администратора)
  - Описание: Откройте Управление дисками, чтобы сжать системный диск на 12288 МБ и создать новый простой том для установочных файлов Windows.
  - Действие: Открывает страницу Windows Settings, Edge или shell URI: `diskmgmt.msc`
  - Инструкция: 1. Щёлкните правой кнопкой по системному диску (C:) → Сжать том. 2. Введите 12288 МБ для сжатия. 3. После сжатия щёлкните правой кнопкой по появившейся нераспределённой области → Создать простой том. 4. Отформатируйте как NTFS, назовите «Win11». 5. Если сжатие не удаётся — см. примечание по устранению проблем ниже.
- **Устранение проблем: невозможно сжать том (журнал USN / файл подкачки)** (id=`no-usb-shrink-errors`; kind=`manual`; control=`checklist`; source=`official`; нужны права администратора)
  - Описание: Если Управление дисками не может сжать том, это может блокировать журнал USN или файл подкачки. Частые ошибки: $Extend\$UsnJrnl (удалить журнал), pagefile.sys (отключить файл подкачки), $Mft::$BITMAP (использовать другой диск или метод).
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: Для удаления журнала USN откройте командную строку от имени администратора и выполните: fsutil usn deletejournal /D C: — затем пересоздайте: fsutil usn createjournal m=0 a=0 C:. Для отключения файла подкачки: Свойства системы → Дополнительно → Параметры быстродействия → Дополнительно → Виртуальная память → Без файла подкачки. Для отключения защиты системы: Свойства системы → Защита системы → выберите C: → Настроить → Отключить. При ошибке $Mft::$BITMAP используйте другой диск или метод установки.
- **Проверить Просмотр событий если сжатие не удаётся** (id=`open-event-viewer-shrink`; kind=`deeplink`; control=`button`; source=`official`)
  - Описание: Если Управление дисками отказывается сжимать том без явного объяснения, Просмотр событий может показать, какой файл блокирует операцию.
  - Действие: Открывает страницу Windows Settings, Edge или shell URI: `eventvwr.msc`
  - Инструкция: В Просмотре событий → Журналы Windows → Приложение ищите события с источником «defrag» в момент неудачной попытки сжатия. В тексте события будет указан файл, препятствующий сжатию.
- **Установка без USB: метод CMD (копирование файлов ISO на раздел Win11)** (id=`no-usb-cmd-method`; kind=`manual`; control=`checklist`; source=`official`; требуется перезагрузка)
  - Описание: Скачайте ISO Windows 11, смонтируйте его в Проводнике (двойной щелчок) и скопируйте все файлы на 12-гигабайтный раздел Win11. Затем загрузитесь с него через Перезагрузка / Дополнительные параметры запуска.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: 1. Скачайте ISO Windows 11. 2. Дважды щёлкните по ISO для монтирования как буква диска. 3. Скопируйте ВСЕ файлы с смонтированного ISO на раздел Win11 (12 ГБ). 4. Для загрузки с него: откройте дополнительные параметры запуска при перезагрузке. Либо просто перезагрузитесь — большинство материнских плат автоматически определят раздел Win11 и загрузятся с него.
- **Скачать EasyBCD (метод без USB 2)** (id=`download-easybcd`; kind=`link`; control=`button`; source=`unofficial`)
  - Описание: EasyBCD добавляет запись загрузки, указывающую на WIM-файл установщика Windows 11 на разделе Win11 — ПК загружается в установщик при следующей перезагрузке без USB-накопителя.
  - Действие: Открывает внешний URL в браузере по умолчанию: `https://neosmart.net/EasyBCD/`
- **Установка без USB: метод EasyBCD** (id=`no-usb-easybcd-method`; kind=`manual`; control=`checklist`; source=`unofficial`; нужны права администратора; требуется перезагрузка)
  - Описание: Используйте EasyBCD для добавления записи загрузки WinPE, указывающей на boot.wim в разделе Win11. При следующей перезагрузке выберите запись NST для запуска установщика Windows 11.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: 1. Скачайте ISO, смонтируйте, скопируйте все файлы на раздел Win11. 2. В разделе Win11 перейдите в папку sources\ и скопируйте путь к boot.wim. 3. Откройте EasyBCD → Добавить новую запись → вкладка WinPE. 4. Вставьте путь к boot.wim в поле Path. Нажмите кнопку +. 5. Сохраните и перезагрузите ПК. В меню загрузки выберите запись NST для запуска установщика.

#### 0.6 Настройки BIOS

- **Примечание AMD: виртуализация может называться SVM или AMD-V** (id=`bios-amd-note`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: На системах AMD параметр виртуализации обычно называется SVM, SVM Mode или AMD-V вместо Intel VT-x. Отключите его для возможности отключения VBS / Core Isolation в Defender.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS найдите: SVM Mode, SVM или AMD-V. Это аналог Intel VT-x на платформе AMD. Отключайте только если не используете виртуальные машины — это позволяет отключить функции безопасности Windows VBS.
- **Отключить предустановленное ПО производителя (MSI Center, ASUS Armoury Crate и др.)** (id=`bios-disable-preinstalled-software`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: Некоторые производители материнских плат предустанавливают bloatware через BIOS (MSI Center, ASUS Armoury Crate). Отключите это в BIOS до установки Windows, чтобы нежелательное ПО не установилось автоматически.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS найдите настройки, связанные с «APP Center Download & Install», «Armoury Crate», «MSI Center» или аналогичными. Отключите их, чтобы предотвратить автоматическую установку ПО производителя на новую Windows.
- **Отключить поддержку CSM и включить Secure Boot** (id=`bios-csm-secureboot`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: Windows 11 требует UEFI с включённым Secure Boot. Полностью отключите CSM (Compatibility Support Module) и установите Secure Boot в значение «Включено». Необходимо для корректной UEFI-установки.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS: (1) Найдите CSM (Compatibility Support Module) и установите «Выключено». (2) Найдите Secure Boot и установите «Включено». Если Secure Boot не включается при активном CSM, сначала отключите CSM, затем включите Secure Boot. Сохраните и перезагрузитесь для подтверждения режима UEFI.
- **Включить TPM 2.0 (Intel PTT, AMD fTPM или физический модуль TPM)** (id=`bios-tpm`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: Windows 11 требует TPM 2.0. Включите его в BIOS — у Intel это «Intel PTT», у AMD — «AMD fTPM». Физические модули TPM также поддерживаются.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS найдите: Intel Platform Trust Technology (PTT) — установите «Включено», или AMD fTPM — установите «Включено». При наличии физического модуля TPM включите «Discrete TPM». После установки Windows подтвердите активацию TPM 2.0: Win+R → tpm.msc.
- **Отключить неиспользуемые устройства (аудио, iGPU если не нужен) — только для десктопа** (id=`bios-disable-unused-devices`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: На десктопных ПК можно отключить неиспользуемые интегрированные устройства (встроенный звук, iGPU) в BIOS для снижения нагрузки и потенциальных конфликтов драйверов. Не рекомендуется для ноутбуков.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS (только для десктопа): рассмотрите отключение встроенного звука при использовании дискретной звуковой карты и отключение iGPU при использовании исключительно дискретного GPU без подключения монитора к интегрированным видеовыходам. НЕ отключайте iGPU на ноутбуке — экран зависит от него.
- **Отключить виртуализацию (если не нужна) — отключает VBS** (id=`bios-disable-virtualization`; kind=`manual`; control=`checklist`; source=`unofficial`)
  - Описание: Отключение виртуализации CPU (Intel VT-x / AMD SVM) в BIOS не позволяет Windows включить Virtualization Based Security (VBS), незначительно снижающую производительность в играх. Отключайте только если не используете ВМ или WSL2.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS найдите: Intel Virtualization Technology (VT-x) или AMD SVM Mode. Установите «Выключено». Это не позволит Credential Guard и Core Isolation в Windows Defender использовать VBS, что может незначительно улучшить производительность в играх. Внимание: после отключения WSL2 и Hyper-V будут недоступны.
- **Отключить неиспользуемые диски в BIOS (если поддерживается)** (id=`bios-disable-extra-drives`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: Если BIOS поддерживает программное отключение отдельных накопителей, отключите диски, не участвующие в установке — это упростит экран выбора диска.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS → конфигурация накопителей отключите все диски, не задействованные в установке Windows (например, дополнительные диски с данными). Это исключит случайный выбор не того диска. После завершения установки включите их обратно.
- **Включить режим PWM для 4-контактных вентиляторов** (id=`bios-pwm-fans`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: Переведите 4-контактные разъёмы вентиляторов в режим PWM (не DC/Voltage) в BIOS для корректного управления оборотами системой охлаждения. Необходимо для точного контроля кривой вентиляторов.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В BIOS → Мониторинг оборудования / управление вентиляторами установите для каждого 4-контактного разъёма режим PWM. В режиме DC скорость вентилятора регулируется напряжением и менее точна. Режим PWM обеспечивает точное управление оборотами через рабочий цикл.

#### 0.7 Важные примечания перед установкой

- **ПК снова запускает установщик вместо OOBE — прочитайте это** (id=`oobe-loop-note`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: После завершения установки и перезагрузки некоторые материнские платы (особенно MSI) не переключают приоритет загрузки на новый раздел Windows и снова запускают установщик. Windows УЖЕ установлена — следуйте инструкции для решения без переустановки.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: УСТАНОВКА С USB: просто извлеките USB-накопитель и перезагрузите ПК. Система загрузится в только что установленную Windows и продолжит начальную настройку (OOBE). Подключите USB снова после выхода на рабочий стол. УСТАНОВКА БЕЗ USB: если снова появляется экран установки, войдите в BIOS и измените приоритеты UEFI Hard Drive BBS, поставив нужный раздел Windows первым (например, в BIOS MSI → Settings → Boot → UEFI Hard Drive BBS Priorities). Если BIOS не позволяет изменить приоритет раздела (часто встречается на ноутбуках MSI): нажмите Shift+F10 на экране установки для открытия командной строки. Выполните: diskpart → list vol → select vol N (где N — раздел Win11 ~12 ГБ) → delete vol. Перезагрузите ПК. Система загрузится с установленного раздела. Важно: это удалит установочный раздел — скачайте нужные файлы с другого ПК или телефона до подключения к интернету.

#### 0.9 Начать установку

- **Перезагрузить ПК и загрузиться с USB-носителя** (id=`boot-from-usb`; kind=`deeplink`; control=`button`; source=`official`; требуется перезагрузка)
  - Описание: Перезагрузите ПК и войдите в меню загрузки (обычно F8, F11, F12 или Del в зависимости от материнской платы) для выбора USB-накопителя. Запустится установщик Windows 11.
  - Действие: Открывает страницу Windows Settings, Edge или shell URI: `ms-settings:recovery`
  - Инструкция: Вариант А: удерживайте Shift и нажмите «Перезагрузить» → Диагностика → Дополнительные параметры → Параметры встроенного ПО UEFI для входа в BIOS, затем измените порядок загрузки на USB. Вариант Б: перезагрузите обычным способом и нажмите F11/F12 (зависит от платы) на заставке производителя для открытия однократного меню загрузки.
- **Загрузиться в установщик: метод CMD без USB (перезагрузка в режим восстановления)** (id=`boot-no-usb-cmd`; kind=`deeplink`; control=`button`; source=`official`; требуется перезагрузка)
  - Описание: При использовании метода без USB через CMD: перезагрузитесь в режим восстановления Windows для доступа к установочному разделу Win11. Подробности — в инструкции.
  - Действие: Открывает страницу Windows Settings, Edge или shell URI: `ms-settings:recovery`
  - Инструкция: Перейдите в Параметры → Система → Восстановление → Особые варианты загрузки → Перезагрузить сейчас. В меню восстановления выберите «Использовать устройство» и укажите раздел Win11. Либо удерживайте Shift при нажатии «Перезагрузить».
- **Загрузиться в установщик: метод EasyBCD без USB (выбрать запись NST при перезагрузке)** (id=`boot-no-usb-easybcd`; kind=`deeplink`; control=`button`; source=`official`; требуется перезагрузка)
  - Описание: Если вы добавили запись загрузки WinPE через EasyBCD — просто перезагрузите ПК и выберите запись «NST» в диспетчере загрузки Windows для запуска установщика.
  - Действие: Открывает страницу Windows Settings, Edge или shell URI: `ms-settings:recovery`
  - Инструкция: Перезагрузите ПК. На экране диспетчера загрузки Windows выберите запись NST (NeoSmart Technologies). Это загрузит установщик WinPE, настроенный через EasyBCD. Далее выполните обычную установку Windows 11.

#### 3.3 Удалить Edge (опционально)

Пошаговый сценарий: массовые чекбоксы выбора скрыты, чтобы не нарушить порядок шагов. Нижняя кнопка применяет следующий невыполненный шаг сверху вниз; ручные пункты отмечайте выполненными только после фактического действия.

- **Прочитайте перед продолжением — зависимость от WebView2** (id=`remove-edge-webview2-warning`; kind=`manual`; control=`checklist`; source=`official`)
  - Описание: Удаление Edge без автономного WebView2 Runtime нарушит работу: Teams, нового Outlook, PWA-приложений, Виджетов Windows. Сначала установите его через «Установить браузер» → WebView2 Runtime.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: Убедитесь, что «WebView2 Runtime (автономный)» уже установлен (подраздел «Установить браузер» → Применить). Только после этого переходите к шагам ниже.
- **Шаг 1 — Проверить, доступно ли удаление** (id=`remove-edge-step1-check`; kind=`deeplink`; control=`button`; source=`official`)
  - Описание: Откройте «Приложения и возможности» и найдите Microsoft Edge. Если кнопка «Удалить» активна (не серая) — перейдите к шагу 6 и удалите напрямую.
  - Действие: Открывает страницу Windows Settings, Edge или shell URI: `ms-settings:appsfeatures`
  - Инструкция: Найдите «Microsoft Edge». Если кнопка «Удалить» доступна — нажмите её, готово. Если недоступна (серая) — выполните шаги 2–6.
- **Шаг 2 — Предоставить права на запись в файл региональной политики** (id=`remove-edge-step2-takeown`; kind=`script`; control=`button`; source=`unofficial`; нужны права администратора)
  - Описание: Выполняет takeown и icacls для IntegratedServicesRegionPolicySet.json, чтобы разрешить редактирование. Необходимо, так как файл принадлежит TrustedInstaller.
  - Действие: Выполняет PowerShell scriptblock из манифеста. Apply: да; Revert: нет; Detect: да. Ключевые команды: `Apply: { $f = "$env:SystemRoot\System32\IntegratedServicesRegionPolicySet.json" & takeown.exe /f $f 2>&1 | Out-Null & icacls.exe $f /grant "${env:USERNAME}:(F)" 2>&1 | Out-Null }`; `Detect: { $f = "$env:SystemRoot\System32\IntegratedServicesRegionPolicySet.json" $acl = Get-Acl $f -EA SilentlyContinue $acl -and ($acl.Owner -notlike '*TrustedInstaller*') }`
- **Шаг 3 — Открыть файл политики в Блокноте** (id=`remove-edge-step3-open-json`; kind=`script`; control=`button`; source=`unofficial`)
  - Описание: Открывает IntegratedServicesRegionPolicySet.json в Блокноте для ручного редактирования. Сначала выполните шаг 2.
  - Действие: Выполняет PowerShell scriptblock из манифеста. Apply: да; Revert: нет; Detect: нет. Ключевые команды: `Apply: Start-Process notepad.exe -ArgumentList $f`
- **Шаг 4 — Найти запись Edge и активировать удаление** (id=`remove-edge-step4-edit-json`; kind=`manual`; control=`checklist`; source=`unofficial`)
  - Описание: В JSON-файле найдите запись «MicrosoftEdge». В массиве «regions» добавьте двухбуквенный код вашей страны (например, «RU», «US», «DE»). Сохраните файл через Ctrl+S.
  - Действие: Ручной чеклист. Автоматических изменений нет; клик по плашке только отмечает пункт как выполненный.
  - Инструкция: В Блокноте нажмите Ctrl+F и найдите «MicrosoftEdge». Найдите ближайший массив «regions» (обычно выглядит как "regions":[""] или похоже). Добавьте двухбуквенный код страны внутрь массива, например: "regions":["RU"]. Сохраните файл через Ctrl+S, затем закройте Блокнот.

  - Действие: Открывает страницу Windows Settings, Edge или shell URI: `ms-settings:appsfeatures`
  - Инструкция: Найдите Microsoft Edge → нажмите ⋮ → Изменить. Дождитесь завершения восстановления. Полностью закройте это окно (включая все процессы Edge).

  - Описание: Снова откройте «Приложения и возможности» — кнопка «Удалить» для Edge должна стать активной. Нажмите её для удаления Edge.

#### 4.6 Управление питанием USB

- **Отключить энергосбережение у всех устройств, где оно есть** (id=`usb-disable-power-mgmt`; kind=`script`; control=`button`; source=`unofficial`; нужны права администратора)
  - Описание: Снимает галку «Разрешить отключение этого устройства для экономии энергии» у всех устройств, где она есть: USB-хабы и контроллеры, сетевые адаптеры, устройства ввода, последовательные/USB-переходники. Устраняет случайные отключения ценой некоторого расхода энергии в простое. Откат вернёт только те устройства, которые изменила эта карточка.
  - Действие: Выполняет PowerShell scriptblock из манифеста. Apply: да; Revert: да; Detect: да. Работает через WMI-класс `MSPower_DeviceEnable`: карточка сообщает, сколько устройств с управлением питанием есть в системе и у скольких энергосбережение было отключено до и после. Список изменённых устройств сохраняется в бэкап `usb-disable-power-mgmt.restore`, поэтому откат возвращает только их и не трогает то, что вы настроили вручную.
  - Примечание о широте охвата: прилагаемый подписанный скрипт `Assets\Scripts\DisableUSBPowerManagement.ps1` задумывался как фильтр по последовательным портам, но из-за потерянного свойства `PNPDeviceID` его условие вырождается и совпадает со всеми устройствами с управлением питанием. Это поведение сохранено намеренно — именно оно и лечит случайные отключения, — а заголовок и описание выше приведены в соответствие с ним.

## Справочник по безопасной работе

Смысл карточки определяется типом действия. `link` и `deeplink` только открывают страницу Windows, папку, URL или внешнюю утилиту. `script` может изменить состояние системы. Ручной чек-лист требует самостоятельно выполнить шаги и проверить результат. Открытие инструмента не означает автоматического применения его настроек.

Перед изменением дисков, загрузки, реестра, прошивки, драйверов, конфиденциальности или политик безопасности подготовьте проверенный путь отката. В зависимости от операции это может быть точка восстановления, экспорт ветки реестра, пакет драйвера, ключ восстановления BitLocker, образ системы, профиль BIOS или отдельная резервная копия.

## Рекомендуемый порядок

Используйте разделы как последовательность зависимостей: сначала Windows и восстановление, затем драйверы чипсета, сети, накопителей и дисплея, проверка дисков, основные параметры Windows, браузеры, GPU, монитор, охлаждение, игры, устройства ввода и только после этого опциональные настройки задержки. Дополнительные твики проверяйте измерениями до и после.

Не применяйте несколько изменений производительности одновременно. Одно действие за раз позволяет связать нестабильность, ухудшение задержки или проблемы с температурой и питанием с конкретной причиной.

## Проверка драйверов и обновлений

До установки драйвера подтвердите идентификаторы оборудования и модель системы. Если производитель устройства или компьютера предоставляет платформенный пакет, сначала рассматривайте его. Перед прошивкой или обновлением контроллера хранения создайте путь восстановления. После установки проверьте Диспетчер устройств, Просмотр событий, требование перезагрузки и фактическую версию драйвера.

Не запускайте общее удаление драйверов, если текущий пакет нужен для загрузки накопителя, вывода изображения, сети или восстановления.

## Диски и хранение

Проверяйте диск по модели, серийному номеру, объёму и разделам, а не только по букве. Буквы и порядок съёмных накопителей могут измениться. До инициализации, преобразования, разметки, форматирования, шифрования или очистки сохраните данные и ключи восстановления.

После операции проверьте загрузку, состояние BitLocker, файловую систему, ожидаемые разделы, свободное место и доступность резервной копии.

## Экран, GPU и охлаждение

Зафиксируйте исходные разрешение, частоту, цветовой режим, версию драйвера GPU, температуры, поведение вентиляторов и стабильность. Настройки изображения и производительности применяйте раздельно. Убедитесь, что монитор подключён нужным интерфейсом, работает на выбранной частоте, а охлаждение безопасно при длительной нагрузке.

Разгон, снижение напряжения, кривые вентиляторов и лимиты мощности требуют измерений и понятного способа сброса. Профиль, выдержавший короткий тест, может оказаться нестабильным в долгой игре или вычислительной нагрузке.

## FPS и задержка

Используйте одинаковые тестовые сцены, фоновые процессы, схему питания и инструменты. Сравнивайте не пиковый FPS, а средние значения, редкие кадры, ровность времени кадра, задержку ввода, температуру, частоты и мощность.

Timer Resolution и другие инструменты задержки опциональны. Не складывайте несколько утилит и не оставляйте необъяснимый фоновый процесс. Проверяйте, отменяется ли изменение после перезагрузки или выхода, если именно это заявлено.

## Сеть, браузер и конфиденциальность

До применения пресета оцените учётные записи, синхронизацию, прокси, DNS, сертификаты, расширения, телеметрию и политики. Управляемый организацией компьютер может восстановить параметры или отклонить локальные изменения. Не ослабляйте защиту Windows или браузера только ради исчезновения предупреждения.

## Восстановление после проблемы

Прекратите применять новые карточки. Запишите последнее изменение, симптомы, состояние после перезагрузки и важные строки журнала. Начинайте с самого узкого отката — верните отдельный параметр или драйвер до общего восстановления системы. При сбое загрузки или хранилища используйте подготовленный носитель и ключи, а не импровизированные разрушительные команды.

## Проверка завершения

- В Windows Update и Диспетчере устройств нет необъяснимых ошибок.
- Проверены накопители, шифрование, резервные копии и путь восстановления.
- Разрешение, частота, цвет и масштаб соответствуют задаче.
- Охлаждение стабильно под нагрузкой.
- Для дополнительных твиков есть сравнимые измерения до и после.
- Известны все утилиты автозапуска, трея, таймера и фоновых задач.
- Важные параметры и способы отката зафиксированы.

## Поддержка карты интерфейса

Манифесты являются структурным источником порядка разделов, названий карточек, элементов управления, предупреждений и команд. Руководство остаётся человеческим слоем: объясняет условия, риск, ожидаемый эффект, проверку и откат. При добавлении или переименовании карточки синхронизируйте оба слоя, презентацию и обучающие материалы.

При выпуске проверяйте, что у каждого видимого действия есть понятное описание, а опасные операции заранее сообщают о правах администратора, перезагрузке, службах, драйверах, реестре, дисках, конфиденциальности или сети. Поле `MaxMovGuide = $true` означает точное присутствие шага в гайде; `MaxMovApproved = $true` добавляется только после отдельного явного одобрения Max.mov. Оба поля меняют только подписи карточек, но не их действия.
